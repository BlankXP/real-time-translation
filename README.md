# BPFlow 实时翻译

一个 Chrome 浏览器扩展（Manifest V3）：在任意网页上实时翻译，支持**双语对照 / 替换原文 / 悬停查看**三种展示模式，并在设置面板中自由切换翻译引擎与 AI 模型。

## 功能特性

- **实时页面翻译** — 智能扫描页面文本块，双语对照插入译文；SPA 动态内容自动增量补翻（MutationObserver）

- **三种展示模式** — 双语对照（默认，保留原文排版）、替换原文（DOM 结构与事件保留，可随时还原）、悬停查看（页面零侵入）

- **自选翻译引擎 / 模型**

  - 内置免费：Bing 翻译（Edge 同源接口，默认）、Google 翻译、MyMemory

  - AI 模型：任意 **OpenAI 兼容接口**（DeepSeek / Kimi / 智谱 GLM / 通义千问 / Groq / 硅基流动 / Ollama 本地模型…），内置一键预设

  - DeepL 官方 API（免费版 / Pro）

  - 每个引擎可单独命名、编辑、启用停用、连接测试

- **语言管理** — 默认翻译方向、常用快捷语言、自定义语言（支持 33 种内置语言）

- **译文样式** — 译文颜色 / 字号 / 「译」徽标，设置页带实时预览

- **站点规则** — 指定站点自动翻译、站点黑名单

- **译文缓存** — 相同文本不重复请求，节省 API 额度；并发数可调

- **划词翻译** — 选中文字 → 浮条 / 右键「BPFlow：翻译选中文字」，一键翻译与复制

- **视频字幕实时翻译** — YouTube / Bilibili / 任意带 CC 字幕的 HTML5 视频：开启播放器字幕后自动叠加双语字幕层（可只显示译文）；视频无原生字幕时也可用工具栏弹窗 / 右键菜单 / `Alt+Shift+L` 手动开启语音识别实时翻译，与直播字幕一致

- **直播语音翻译** — Twitch / 斗鱼 / 虎牙 / 抖音直播等无字幕场景：捕获本页声音 → 实时转写 → 翻译成滚动字幕。转写引擎支持两套独立配置：**阿里云百炼**（模型下拉选择，接口地址按模型自动推导，HTTP 分片上传）与 **OpenAI 兼容** `/audio/transcriptions`（5 秒分片，延迟约 6 秒+）。两种引擎的字幕观感一致：一段一段显示、一段一段翻译。出于 Chrome 安全限制，需从工具栏弹窗 / 右键菜单 / `Alt+Shift+L` 启动

- **快捷键** — `Alt+Shift+Y` 翻译 / 还原当前页

- **悬浮球** — 页面右下角可拖拽悬浮球，点击展开快捷面板（改语言、切模式、开关翻译、开直播字幕）

- 深色高端 UI、Shadow DOM 样式隔离、打印时自动隐藏译文

## 安装（开发者模式加载）

1. 打开 Chrome，访问 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（`real-time-translation/`，即包含 `manifest.json` 的目录）
4. 工具栏出现「译」图标即安装成功

> 提示：如需翻译本地 `file://` 页面（如 `demo/index.html`），请在扩展详情页打开「允许访问文件网址」。

## 快速上手

1. 点击工具栏图标打开弹窗（或使用页面右下角悬浮球）
2. 选择目标语言与展示模式
3. 点亮「翻译此页面」开关，或按 `Alt+Shift+Y`
4. 再次操作即可还原原文

测试多语言效果可打开 `demo/index.html`（含英 / 日 / 德 / 法 / 混排与动态加载内容）。

## 接入自己的 AI 模型（示例：DeepSeek）

1. 打开 设置 → 引擎模型 → **添加引擎**
2. 类型选「AI 模型」，点击预设 **DeepSeek**（自动填入 `https://api.deepseek.com/v1` 与 `deepseek-chat`）
3. 粘贴你的 API Key → 保存 → 点「测试」验证连通
4. 点击该引擎卡片左侧圆点，设为当前引擎

其他平台同理：Kimi、智谱 GLM、通义千问、Groq、硅基流动均有预设；本地 Ollama 用 `http://localhost:11434/v1`。也支持任何自定义 OpenAI 兼容接口（可自定义提示词模板，变量：`{source}` `{target}` `{texts}`）。
推荐使用阿里云百炼,新人注册会送大量token。

## 视频与直播字幕

### 视频字幕翻译（YouTube / Bilibili / 通用 HTML5）

1. 设置 → 视频直播 → 打开「视频字幕翻译」（默认开启）
2. 打开一个带 CC 字幕的视频（YouTube 自动生成字幕即可），在播放器中**开启字幕**
3. 双语字幕层自动出现：原文 + 译文（可在设置中改为只显示译文），字号随播放器自适应

原理：内容脚本观察播放器的字幕 DOM（YouTube `.ytp-caption-segment`、B 站字幕行 / 通用 `<track>` 的 `cuechange`），新字幕行出现即调用当前翻译引擎（含缓存），覆盖层渲染在播放器内、全屏可用；接管后自动隐藏原生字幕避免重复。视频无原生字幕时，用与直播相同的方式手动开启语音翻译即可（工具栏弹窗 / 右键菜单 / `Alt+Shift+L`）。

### 直播语音翻译（Twitch / 斗鱼 / 虎牙 / 抖音直播等）

基于 `tabCapture` 捕获标签页声音，**理论上适用于任何网站**；已为 Twitch / 斗鱼 / 虎牙 / 抖音直播内置播放器锚定（字幕层精准贴在播放器内），其余平台自动走通用锚定（主视频的定位父级，无视频时退化为页面底部固定层）。若平台把播放器放在跨域 iframe 内（部分页面如此），字幕层锚定在页面底部，转写与翻译功能不受影响。

1. 设置 → 视频直播 → 选择**转写引擎**（阿里云百炼 / OpenAI 兼容），填入对应配置

   两套配置**相互独立**，切换引擎不会覆盖另一套：

   | 引擎        | 配置项                              | 说明                                                                                      |
   | --------- | -------------------------------- | --------------------------------------------------------------------------------------- |
   | **阿里云百炼** | 模型（下拉选择）+ API Key + 自定义地址（可选）  | 接口地址、协议、采样率**按所选模型自动推导**，无需手填                                                          |
   | OpenAI 兼容 | Base URL + 模型 + API Key（含 Groq / 硅基流动等快速预设） | 走 `/audio/transcriptions`，5 秒分片上传，延迟约 6 秒+                                               |

   百炼支持的模型与自动推导结果：

   | 模型                            | 类型     | 自动使用的接口地址                                          | 采样率    | 特点                                 |
   | ----------------------------- | ------ | ------------------------------------------------- | ------ | ---------------------------------- |
   | `paraformer-v1` / `paraformer-v2` | 普通（非实时） | `https://dashscope.aliyuncs.com/api/v1/services/audio/asr/transcription` | 16 kHz | 录音文件转写（异步任务），**只接受公网可访问的音频 URL，直播链路不可用** |
   | `fun-asr-flash-2026-06-15`    | 普通（非实时） | `https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation` | 16 kHz | 5 秒分片（Base64 内嵌），延迟约 6 秒+          |

   > 使用百炼**专属端点**时，在「自定义接口地址」填写 `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1`，`{WorkspaceId}` 必须替换为真实业务空间 ID；留空则使用上表的官方公共地址。注意：业务空间专属端点通常只服务该空间内部署的模型——若空间内未部署 ASR 模型，转写会持续报 HTTP 400（空错误体），此时请清空自定义地址，改用官方公共地址。

2. 打开直播页，用以下**任意一种**方式启动（任一操作都会切换 / 停止）：

   | 方式    | 操作                                 |
   | ----- | ---------------------------------- |
   | 工具栏弹窗 | 点击浏览器工具栏的「译」图标 → 直播字幕 → **开始**     |
   | 右键菜单  | 页面右键 → 「BPFlow：直播字幕翻译（捕获本页声音）」 |
   | 快捷键   | `Alt+Shift+L`                      |

   > Chrome 的 `tabCapture` 要求扩展先被用户「唤起」（与 activeTab 同理）才允许捕获页面音频，因此**必须由上面三种扩展自身的手势发起**。页面悬浮球面板的「直播字幕」按钮在已唤起的情况下同样可用来停止（或再次启动），否则会提示改用工栏弹窗 / 右键菜单 / 快捷键。

3. 扩展捕获本页声音（`tabCapture` + offscreen 文档），实时翻译成滚动字幕；播放器右上角有「直播翻译中」徽标，点 ✕ 或再次执行上面的操作即可停止

文本翻译走你当前选择的翻译引擎；声音正常播放不受影响。直播页按 F12 打开 Console，`LF-` 前缀日志可查看全链路状态（捕获 → 转写 → 翻译 → 上屏）。

**音频规格**：
- 百炼 / OpenAI 兼容引擎均为 **WAV 16kHz 单声道**、约 5 秒一片上传（Base64 后约 0.2MB）

**本地预过滤**（VAD）：每片上传前先做本地语音活动检测——整片静音（RMS<0.005）或无人声特征（基于帧能量 + 自相关基频：白噪声/音效/轰鸣/电源嗡嗡等）的片段直接跳过，不发无效请求、不烧额度。策略保守（宁可放行）：旋律音乐等难判定内容仍上传，由服务端判定兜底，避免误杀正常说话。

**同步延迟 / 画面同步（可选）**：识别与翻译天然耗时，字幕必然滞后。可在 设置 → 视频直播 调节「同步延迟」（0\~30 秒）：

- **不开启「同步画面」**：只延迟回放给用户的声音，字幕按「语音时刻 + 延迟」定时上屏，与听到的语音对齐（画面实时，会领先声音）

- **开启「同步画面」**：视频、声音、字幕三者一起延迟——内容脚本用 `video.captureStream()` 抓取播放器媒体流（解码帧，非屏幕像素，无回环），经 MediaRecorder 1 秒分片 → N 秒队列 → MSE 覆盖层延迟重放，覆盖在原视频上方（原视频全程未被修改，停止即恢复；播放器控制条仍可用）

延迟取值建议 ≥ 字幕链路耗时（约 8\~10 秒），从小到大微调到「字随画走」。修改设置后需重新开启直播字幕生效。

**画面延迟微调**：画面链路（1 秒分片 + MSE 缓冲）的固有延迟比声音链路（DelayNode 精确延迟）多约 1\~1.5 秒，可能出现口型与声音对不上。可在设置中单独微调画面延迟（±3 秒，步进 0.25 秒）：**画面慢于声音 → 负值**。精确设定方法：直播页控制台执行 `window.__LF_SYNC_DEBUG__()`，`measuredVideoDelayMs` 为实测画面延迟，减去声音延迟即为偏差，将微调设为该偏差的相反数即可对齐。字幕与声音对齐，不参与画面微调。

**画质与流畅**：录制码率按源分辨率自适应（1080p≈8Mbps / 720p≈3.5Mbps，VP8 编码优先——比 VP9 编码负担低、长时间更稳）；分片「永不丢弃」——追加与缓冲回收冲突时自动重试，避免时间戳跳变引发的撕裂花屏；缓冲回收仅在追加空闲时执行；内置 stall 看门狗（播放停滞时跳至缓冲尾部恢复、轻微落后时 1.02 倍速追赶）。CPU 占用较高时（长时直播 + 高分辨率），可在浏览器任务管理器观察「扩展进程」，必要时降低直播清晰度以减轻编码负担。

### 接入阿里云百炼（DashScope）

设置 → 视频直播 → 转写引擎选「阿里云百炼」，在**模型下拉框**里选择即可，接口地址 / 协议 / 采样率全部自动推导：

- 普通模型（`fun-asr-flash-2026-06-15`）走 `POST {base}/services/aigc/multimodal-generation/generation`，音频以 `data:audio/wav;base64,<base64>` 内嵌（官方支持，无需先传 OSS），带 `X-DashScope-SSE: disable` 关闭流式

- `paraformer-v1` / `paraformer-v2` 属于百炼「录音文件识别」异步接口（`POST {base}/services/audio/asr/transcription`，需提交任务后轮询），**只接受公网可访问的音频 URL**，浏览器本地音频无法提交，扩展会在启动时直接提示改用其他模型

- 响应解析按模型代次自动适配：fun-asr 系读 `output.text` / `output.sentence.text`；旧 `qwen3-asr` 系读 `output.choices[0].message.content`

- 源语言会自动归一为 ISO-639-1 短码（如 `zh-CN` → `zh`）

- 成本提示：5 秒一片 = 每小时约 720 次请求

## 项目结构

```
real-time-translation/
├── manifest.json           # MV3 清单
├── background/
│   └── background.js       # Service Worker：引擎适配、批量调度、并发、LRU 缓存、快捷键、右键菜单、直播调度
├── content/
│   ├── content.js          # 内容脚本：DOM 扫描、翻译应用、悬浮球（Shadow DOM）、增量翻译、划词浮条
│   ├── video.js            # 内容脚本：视频字幕翻译覆盖层、直播滚动字幕
│   └── content.css         # 译文展示样式（lf-* 前缀隔离）
├── offscreen/              # offscreen 文档：tabCapture 音频捕获、滚动分片录音、ASR 转写
├── popup/                  # 工具栏弹窗：开关 / 语言 / 模式 / 引擎
├── options/                # 设置页：引擎管理 / 语言管理 / 显示效果 / 视频直播 / 高级设置
├── shared/
│   ├── langs.js            # 语言表与编码映射（Bing / DeepL / Google）
│   ├── defaults.js         # 默认设置与 AI 平台 / 语音转写预设
│   └── preview-shim.js     # 浏览器直接打开 UI 时的预览垫片
├── icons/                  # 16 / 48 / 128 图标
├── scripts/
│   └── make_icons.py       # 图标生成脚本（Pillow）
└── demo/index.html         # 多语言测试页
```

## 架构说明

- **消息流**：内容脚本收集文本块并去重 → 分批（16 条/批）发往 Service Worker → 按引擎特性再分片（Bing 20 条/请求、AI 模型 16 条 JSON 数组往返、Google/MyMemory 逐条）→ 并发池执行 → 结果按序回填

- **缓存**：`引擎+模型+方向+文本` 哈希为键，内存 LRU + `chrome.storage.local` 持久化，上限可配置

- **无污染还原**：替换模式将原文收纳进隐藏的 `<lf-original>` 容器而非销毁，还原时原样迁回，页面事件监听不丢失

- **样式隔离**：所有注入 UI（悬浮球 / 面板 / 进度条 / Tooltip）位于 Shadow DOM 内，页面 CSS 互不影响

## 已知限制

- AI 模型引擎的译文数量依赖模型输出 JSON 的稳定性，个别模型偶发不对齐时会按行兜底或提示失败

- 「替换原文」模式下段内链接会暂时失去可点击性（译文为纯文本），切回双语或还原即恢复

- 浏览器内部页面（`chrome://`、Web Store 等）无法注入内容脚本

- Google 免费接口为逐句请求，长页面首次翻译耗时略长（有缓存后秒开）

- 视频字幕依赖视频自带 CC（无 CC 时可手动开启语音识别翻译）；Bilibili 字幕 DOM 若改版需更新选择器

- 直播转写：OpenAI 兼容 / 百炼 JSON 协议均按约 5 秒分片，片间可能有极小概率漏词；画中画（PiP）窗口不显示字幕层

- 直播语音翻译需配置转写引擎（免费文本引擎不含语音识别能力）；若提示「本页已有未释放的音频捕获」（常见于扩展重载后），刷新页面即可恢复

- 各直播平台页面结构各异，内置选择器未命中时自动走通用锚定；平台改版导致字幕层位置偏移属正常，转写翻译不受影响
