视频与直播字幕

把视频 CC 字幕与直播语音，变成实时双语字幕。

视频字幕翻译 YouTube / Bilibili / 任意带 CC 字幕的 HTML5 视频
需要视频自带 CC 字幕（YouTube 自动生成字幕即可）：在播放器中开启字幕后，双语字幕层会自动接管显示。画中画（PiP）窗口内不显示。
直播语音翻译 Twitch / 直播间等没有字幕的场景

三种启动方式任选：弹窗（点工具栏图标 → 直播字幕 → 开始）、右键菜单「BPFlow：直播字幕翻译」、快捷键 Alt+Shift+L。页面悬浮球面板的按钮在浏览器尚未「唤起」扩展时会提示改用以上方式。

流程：捕获本页声音 → 实时语音转写 → 翻译成滚动字幕；声音保持正常播放，文本翻译使用你当前选择的翻译引擎。

两套配置相互独立：切换引擎不会覆盖另一套的地址 / 模型 / 密钥。阿里云百炼按所选模型自动推导协议与接口地址（HTTP 分片上传）；OpenAI 兼容走 /audio/transcriptions，5 秒分片上传
使用百炼专属端点（形如 https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/api/v1）时填写，需把 {WorkspaceId} 替换为真实业务空间 ID。注意：业务空间端点通常只服务空间内部署的模型，若转写持续报 HTTP 400，请清空此项改用官方地址
字幕链路有时延（识别+翻译），把回放延迟到 ≥ 链路耗时后，字幕会与画面同时出现。建议配 8~10 秒，从小到大微调到「字随画走」。设为 0 关闭。开启「同步画面」时原画面被覆盖层替代（含声音）；不开启则只延迟声音、画面实时。修改后需重新开启直播字幕生效
单独补偿画面相对声音的偏差：画面链路（1 秒分片 + 缓冲）固有延迟比声音多约 1~2 秒。画面慢于声音（口型对不上）→ 负值让画面提前；画面快于声音 → 正值。步进 0.25 秒，对照口型微调。修改后需重新开启直播字幕生效
音频编码为 WAV 16kHz 单声道、约 5 秒一片上传。配置仅保存在你自己的浏览器中
